# Ikemen GO experiment

As of October 31, 2026, the Martin-based browser game is restored as the main working game. Follow [MARTIN-WORKFLOW.md](MARTIN-WORKFLOW.md).

This repository remains an Ikemen source fork. The Ikemen prototype, source and exporter are preserved for future evaluation, rather than used as the main game pipeline.

The experiment verified a custom character's stance and jab in official Ikemen GO v1.0.0. A 20-second test dealt 585 damage to the default Kung Fu Man opponent. The prototype still uses static movement/reaction drawings and basic CPU behavior. See [IKEMEN-CHARACTER-TEST.md](IKEMEN-CHARACTER-TEST.md) for experimental setup and tools/export-ikemen.py for its command-line pose exporter.

New work should use the existing Asset Studio Game Template ZIP export and Martin-based Template Studio import workflow. The local Martin game and its artwork have not been uploaded to this Ikemen fork.
